# SkillBytes – Navigation Flow

## 1. Learner Navigation

1. **Login / Sign Up:** Learners log in or create an account.
2. **Home:** Learners see a welcome message, continue-learning section, recommended programs, and learning progress.
3. **Course Listing:** Learners browse courses and filter them by topics such as Programming, Networking, Electronics, and Hardware Skills.
4. **Course Details:** Learners review the course description, difficulty level, duration, and available modules.
5. **Enrollment:** Learners enroll in a course.
6. **Lessons:** Learners complete short lessons and modules.
7. **Progress / Profile:** Learners review their completed lessons and learning progress.

**Navigation sequence:**

Login / Sign Up → Home → Course Listing → Course Details → Enroll → Lessons → Progress / Profile

## 2. Administrator Navigation

1. Log in using an administrator account.
2. Open the Admin Dashboard.
3. Manage existing courses.
4. Add or edit courses and modules.
5. Review course enrollment information.

**Navigation sequence:**

Login → Admin Dashboard → Manage Courses → Add / Edit Course → Manage Modules

## 3. Main Navigation

The planned learner interface will provide access to:

- Home
- Programs
- Progress
- Profile

## 4. Implementation Status

These navigation flows describe the proposed application design. The screens and navigation will be implemented and tested during subsequent development phases.
