# SkillBytes – User Journeys

## Journey 1: A New Learner Starts a Course

**User:** A first-year student who wants to learn electronics.

1. The student opens SkillBytes.
2. The student signs up using an email address.
3. The Home screen displays available learning tracks.
4. The student selects Electronics.
5. The student browses the course listing.
6. The student opens Arduino Basics.
7. The student reviews the course description and modules.
8. The student selects Enroll.
9. The student starts a short lesson.
10. The student checks their profile or progress screen to review their learning progress.

**Expected outcome:** The learner can discover a course, enroll, begin learning, and track progress.

## Journey 2: A Returning Learner Continues Learning

**User:** A learner who has already started Networking Fundamentals.

1. The learner logs in.
2. The Home screen displays the Continue Learning section.
3. The learner selects the previously started course.
4. The learner resumes the next incomplete lesson.
5. The learner completes the lesson.
6. The application updates the learner's progress.
7. The learner continues to the next module.

**Expected outcome:** The learner can return to an existing course and monitor progress.

## Journey 3: An Administrator Adds a Course

**User:** An administrator responsible for learning content.

1. The administrator logs in.
2. The administrator opens the Admin Dashboard.
3. The administrator selects Add Course.
4. The administrator enters the course title, learning track, difficulty level, and description.
5. The administrator adds modules and lessons.
6. The administrator saves the course.
7. The administrator verifies the course information.

**Expected outcome:** The administrator can organize and maintain course content for learners.

## Note

These journeys describe the planned user experience. Their functionality will be developed and verified in later project phases.
